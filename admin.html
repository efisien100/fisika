Masuk untuk mengelola isi situs

Perubahan disimpan langsung ke repository GitHub-mu. Kamu butuh token akses pribadi, yang hanya berlaku untuk satu repository.

Format pemilik/nama-repository.

Cara membuat token (sekali saja)
  1. Buka GitHub, klik foto profil, lalu Settings > Developer settings > Personal access tokens > Fine-grained tokens.
  2. Klik Generate new token. Beri nama, misalnya “admin kelas”, dan pilih masa berlaku.
  3. Pada Repository access, pilih Only select repositories lalu pilih repository situs ini.
  4. Pada Permissions > Repository permissions, ubah Contents menjadi Read and write.
  5. Klik Generate token, salin, lalu tempel di kolom di atas. Token hanya muncul sekali.

Token tidak pernah dikirim ke tempat lain selain GitHub. Jangan bagikan token ini ke siswa. “Coba tanpa GitHub” membuka data dari situs, lalu kamu mengunduh data.json dan mengunggahnya sendiri ke repository.
